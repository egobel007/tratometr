# Тратометр

Приложение для iPhone: записываешь траты голосом или фото чека, оно само раскладывает их по категориям и показывает, куда ушли деньги за день, неделю и месяц.

## Что внутри

- **Голос.** Нажимаешь на шар и говоришь как есть: «кофе 280, такси до работы 640, вчера Пятёрочка полторы тысячи». Речь распознаёт iPhone (русский язык), после паузы приложение само разбирает фразу на отдельные траты: сумма, категория, описание, дата. Понимает «вчера», «позавчера», «полторы тысячи», «2к», «косарь», «2 кофе по 250».
- **Фото чека.** Системная камера-сканер сама находит края чека, текст читается прямо на телефоне, итог находится автоматически.
- **Проверка перед сохранением.** Всё распознанное показывается карточками: можно поправить сумму, категорию, дату или убрать лишнее. Сохранение одной кнопкой, есть «Отменить».
- **Аналитика.** День, неделя, месяц и листание назад. Кольцевая диаграмма по категориям (нажми на категорию, чтобы раскрыть покупки), столбики по дням со средней линией, сравнение с прошлым периодом.
- **Где сэкономить.** Подсказки по цифрам: какая категория выросла, сколько уходит на мелочь, кофе в пересчёте на год, самый дорогой день недели, прогноз на конец месяца и сколько можно тратить в день при заданном бюджете.
- **Дизайн.** Живой 3D-шар на Metal-шейдере реагирует на голос и подсвечивается цветом категории после записи, карточка с итогами наклоняется вслед за телефоном (гироскоп), анимированные цифры, плавные переходы, тактильный отклик, светлая и тёмная тема.
- **Данные** хранятся только на телефоне. Есть выгрузка в CSV (открывается в Excel и Numbers).
- **Claude по желанию.** Если в Настройках вставить свой ключ Claude API, сложные фразы и мятые чеки будет разбирать Claude, а в аналитике появится кнопка «Разбор от Claude». Без ключа всё работает офлайн.

Требования: iPhone с iOS 17 или новее, Mac с Xcode 16 или новее.

## Как поставить на iPhone (бесплатно)

1. **Xcode.** Установи Xcode из App Store на Mac и один раз запусти его. Если попросит установить компоненты для iOS, соглашайся.
2. **Проект.** Распакуй архив и дважды кликни `Tratometr.xcodeproj`.
3. **Apple ID.** Xcode → Settings → Accounts → «+» → Apple ID. Подойдёт обычный бесплатный.
4. **Подпись.** Слева нажми на синюю иконку проекта «Tratometr», выбери таргет «Tratometr», вкладка **Signing & Capabilities**. В поле **Team** выбери свой «Personal Team».
   Если Xcode пишет, что идентификатор занят, поменяй **Bundle Identifier** на любой свой, например `com.egor123.tratometr`.
5. **iPhone.** Подключи телефон кабелем и нажми «Доверять этому компьютеру».
   Включи режим разработчика: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить, телефон перезагрузится.
6. **Запуск.** Вверху Xcode выбери свой iPhone в списке устройств и нажми ▶ (или Cmd+R). Первая сборка занимает пару минут.
7. **Доверие.** При первом открытии iPhone скажет, что разработчик ненадёжный. Зайди в Настройки → Основные → VPN и управление устройством → свой Apple ID → «Доверять».
8. Разреши доступ к микрофону и распознаванию речи, когда приложение спросит.

Готово, иконка Тратометра на экране «Домой».

**Раз в 7 дней** бесплатная подпись истекает и приложение перестаёт открываться. Подключи iPhone и снова нажми ▶ в Xcode: данные сохраняются. Чтобы не делать это, нужен платный аккаунт разработчика Apple ($99 в год), тогда подпись живёт год.

## Без Xcode: сборка на GitHub + установка через Sideloadly

Если Xcode не ставится (ему нужна macOS Sonoma 14.5 или новее и около 40 ГБ места), приложение можно собрать в облаке GitHub, а поставить на iPhone программой Sideloadly. Тоже бесплатно, с обычным Apple ID.

**1. Собрать .ipa на GitHub**

1. Зарегистрируйся на github.com и нажми **New repository**. Назови, например, `tratometr`, тип **Public** (для публичных сборки бесплатны без лимита), создай.
2. На странице репозитория: **Add file → Upload files**. Перетащи туда всё содержимое папки `Tratometr` (папку `Tratometr`, `Tratometr.xcodeproj`, `README.md`). Нажми **Commit changes**.
3. Открой вкладку **Actions → set up a workflow yourself**. Удали всё в редакторе и вставь содержимое файла `github-workflow (для GitHub Actions).yml`. Нажми **Commit changes**.
4. Сборка запустится сама (вкладка **Actions**, 5-10 минут). Когда появится зелёная галочка, открой сборку и внизу в **Artifacts** скачай `Tratometr-ipa`. Распакуй: внутри `Tratometr.ipa`.
   Если галочка красная, скачай там же `build-log` и пришли мне.

**2. Поставить на iPhone**

1. Скачай Sideloadly с sideloadly.io (есть для Mac и Windows) и установи.
2. Подключи iPhone кабелем, нажми «Доверять этому компьютеру».
3. Перетащи `Tratometr.ipa` в окно Sideloadly, введи свой Apple ID и нажми **Start**. Пароль уходит только в Apple.
4. На iPhone включи режим разработчика: Настройки → Конфиденциальность и безопасность → Режим разработчика.
5. Настройки → Основные → VPN и управление устройством → свой Apple ID → «Доверять».

Раз в 7 дней подпись нужно обновить: снова **Start** в Sideloadly. В его настройках можно включить автообновление по Wi-Fi.

## Если что-то не так

- **Ошибка при сборке.** Сделай скриншот красной ошибки в Xcode (вкладка с восклицательным знаком слева) и пришли мне, поправлю.
- **Голос не работает.** Проверь Настройки iPhone → Тратометр: микрофон и распознавание речи включены. Для лучшего качества нужен интернет, коротко работает и без него.
- **Неверная категория.** Нажми на иконку категории в карточке и выбери нужную. С ключом Claude категории точнее.

## Ключ Claude (необязательно)

1. Зайди на console.anthropic.com → API Keys → Create Key.
2. Скопируй ключ и вставь в Тратометре: Настройки → «Claude, по желанию».

Оплата идёт по факту запросов на console.anthropic.com, отдельно от подписки Claude.

```
  Core/
    Models.swift            трата, категории, валюты
    LocalParser.swift       офлайн-разбор русской речи
    ClaudeService.swift     Claude API (по желанию)
    ReceiptOCR.swift        распознавание чека и сканер
    Speech.swift            распознавание речи и гироскоп
    Analytics.swift         периоды, суммы, подсказки, пример данных
    AppState.swift          общее состояние
    Format.swift            деньги, даты, цвета, связка ключей
  Views/
    RootView, HomeView, ComposeView, StatsView, HistoryView, SettingsView, Components
    Orb.swift + Orb.metal   3D-шар
  Assets.xcassets           иконка
```
